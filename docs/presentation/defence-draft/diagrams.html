EclipsVault diagrams / დიაგრამები

Printable copy of the five C4 pictures in diagrams.md. Colours and type follow Pele's CSS variables. This page does not show a running vault.

diagrams.md-ის ხუთი C4 სურათის საბეჭდი ასლი. ფერები და შრიფტი Pele-ის CSS ცვლადებს მიჰყვება. ეს გვერდი გაშვებულ საცავს არ აჩვენებს.

1. Context / კონტექსტი

svg/01-context.svg

EclipsVault is one software system. A person uses a session, a service account uses an API key, and the three external systems exist only when that integration is configured.

EclipsVault ერთი პროგრამული სისტემაა. ადამიანი სესიას იყენებს, სერვისის ანგარიში API გასაღებს, და სამი გარე სისტემა მხოლოდ მაშინ არსებობს, როცა ეს ინტეგრაცია კონფიგურირებულია.

2. Container / კონტეინერი

svg/02-container.svg

Node and the SDK exist while the image is built. At runtime there is the Web container, the one selected database, and Redis only when it is enabled. Core and Infrastructure stay modules inside Web.

Node და SDK იმიჯის აწყობისას არსებობს. გაშვებისას არის Web კონტეინერი, ერთი არჩეული ბაზა, და Redis მხოლოდ მაშინ, როცა ჩართულია. Core და Infrastructure Web-ის შიგნით მოდულებად რჩება.

3. Web component / Web-ის კომპონენტი

svg/03-web-component.svg

the same access policy serves a session and an API key. The audit page is a Legacy administrator page on this revision.

ერთი და იგივე წვდომის წესი ემსახურება სესიასაც და API გასაღებსაც. ამ რევიზიაზე აუდიტის გვერდი Legacy ადმინისტრატორის გვერდია.

4. Focused code: reveal / გახსნის კოდი

svg/04-reveal.svg

`SecretRevealed` is committed before `UnsealAsync`. The earlier `Viewed` row is the details load, and it is written before the access decision.

`SecretRevealed` ფიქსირდება `UnsealAsync`-მდე. უფრო ადრეული `Viewed` დეტალების ჩატვირთვაა და წვდომის გადაწყვეტამდე იწერება.

5. Deployment / განთავსება

svg/05-deployment.svg

the middle boundary reuses Development. It is not a third product mode, and this draft did not start it.

შუა საზღვარი Development-ს იყენებს. ის მესამე პროდუქტის რეჟიმი არ არის და ამ მონახაზმა ის არ გაუშვა.

EclipsVault diagrams / დიაგრამები

Printable copy of the five C4 pictures in diagrams.md. Colours and type follow Pele's CSS variables. This page does not show a running vault.

diagrams.md-ის ხუთი C4 სურათის საბეჭდი ასლი. ფერები და შრიფტი Pele-ის CSS ცვლადებს მიჰყვება. ეს გვერდი გაშვებულ საცავს არ აჩვენებს.

1. Context / კონტექსტი

svg/01-context.svg

EclipsVault is one software system. A vault account in a browser is a person and uses a session. An application that uses a service account is an external system and calls the Public API with an API key. The identity provider, SMTP, and Vault Transit exist only when that integration is configured.

EclipsVault ერთი პროგრამული სისტემაა. ბრაუზერში მყოფი საცავის ანგარიში პიროვნებაა და სესიას იყენებს. აპლიკაცია, რომელიც სერვისის ანგარიშს იყენებს, გარე სისტემაა და საჯარო API-ს API გასაღებით იძახებს. იდენტობის მომწოდებელი, SMTP და Vault Transit მხოლოდ მაშინ არსებობენ, როცა ეს ინტეგრაცია კონფიგურირებულია.

2. Container / კონტეინერი

svg/02-container.svg

The Angular UI, the Web application, and one database are runtime containers. Redis is a fourth container only when it is enabled. The Angular UI runs in the browser and calls the UI API with the session cookie. The Web application serves the Angular files, the UI API, the Public API, and the Razor sign-in pages that remain. The person and the external systems stay outside the boundary.

Angular UI, Web აპლიკაცია და ერთი ბაზა გაშვების კონტეინერებია. Redis მეოთხე კონტეინერია მხოლოდ მაშინ, როცა ჩართულია. Angular UI ბრაუზერში ეშვება და UI API-ს სესიის ქუქით იძახებს. Web აპლიკაცია Angular-ის ფაილებს, UI API-ს, საჯარო API-ს და დარჩენილ Razor-ის შესვლის გვერდებს აწვდის. პიროვნება და გარე სისტემები საზღვრის გარეთ რჩებიან.

3. Web component / Web-ის კომპონენტი

svg/03-web-component.svg

The vault account loads the Angular files. Those pages call the UI API with the session cookie. Secret details, the audit log, and Encryption keys are Angular routes. `SecretDetailsController` asks `SecretAccessHandler`, records `Viewed` only after allow, and calls `RevealAsync` only after a later allow. The Public API reaches `SecretsApiController` through the API key handler and uses the same policy. Sign-in is still the Razor pages. `AuditController` is the audit log and is `AdminOnly`. SecretService and AuditSink persist through EF Core.

საცავის ანგარიში Angular-ის ფაილებს ტვირთავს. ეს გვერდები UI API-ს სესიის ქუქით იძახებენ. საიდუმლოს დეტალები, აუდიტის ჟურნალი და Encryption keys Angular-ის მარშრუტებია. `SecretDetailsController` ეკითხება `SecretAccessHandler`-ს, `Viewed`-ს მხოლოდ ნებართვის შემდეგ წერს და `RevealAsync`-ს მხოლოდ მომდევნო ნებართვის შემდეგ იძახებს. საჯარო API `SecretsApiController`-ს API გასაღების დამმუშავებლით აღწევს და იმავე წესს იყენებს. შესვლა ჯერ Razor-ის გვერდებია. `AuditController` აუდიტის ჟურნალია და `AdminOnly`-ა. SecretService და AuditSink მონაცემებს EF Core-ით წერენ.

4. Focused code: reveal / გახსნის კოდი

svg/04-reveal.svg

Opening the details page checks access before it commits `Viewed`. Reveal checks access again, commits `SecretRevealed`, and only then calls `UnsealAsync`. The Angular page shows the plaintext once.

დეტალების გვერდის გახსნა წვდომას `Viewed`-ის დაფიქსირებამდე ამოწმებს. გახსნა წვდომას თავიდან ამოწმებს, აფიქსირებს `SecretRevealed`-ს და მხოლოდ შემდეგ იძახებს `UnsealAsync`-ს. Angular-ის გვერდი ღია ტექსტს ერთხელ აჩვენებს.

5. Deployment / განთავსება

svg/05-deployment.svg

Development and production are deployment nodes. Development runs Web on the developer machine and PostgreSQL in the Compose project, because that project's `db` service is PostgreSQL. Production runs the Web image on a Docker host behind a TLS reverse proxy, and its database node may be PostgreSQL or SQL Server. The demonstration is one disposable Development run, not another deployment.

Development და production განთავსების კვანძებია. Development Web-ს დეველოპერის მანქანაზე უშვებს, PostgreSQL-ს კი Compose პროექტში, რადგან ამ პროექტის `db` სერვისი PostgreSQL-ია. Production Web იმიჯს Docker ჰოსტზე უშვებს TLS შებრუნებული პროქსის უკან, და მისი ბაზის კვანძი შეიძლება იყოს PostgreSQL ან SQL Server. დემონსტრაცია Development-ის ერთი ერთჯერადი გაშვებაა, არა სხვა განთავსება.

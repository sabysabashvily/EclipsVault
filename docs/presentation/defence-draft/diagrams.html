EclipsVault diagrams / დიაგრამები

Printable copy of the five C4 pictures in diagrams.md. Colours and type follow Pele's CSS variables. This page does not show a running vault.

diagrams.md-ის ხუთი C4 სურათის საბეჭდი ასლი. ფერები და შრიფტი Pele-ის CSS ცვლადებს მიჰყვება. ეს გვერდი გაშვებულ საცავს არ აჩვენებს.

1. Context / კონტექსტი

svg/01-context.svg

EclipsVault is one software system. A vault account in a browser is a person and uses a session. An application that uses a service account is an external system and calls the Public API with an API key. The identity provider, SMTP, and Vault Transit exist only when that integration is configured.

EclipsVault ერთი პროგრამული სისტემაა. ბრაუზერში მყოფი საცავის ანგარიში პიროვნებაა და სესიას იყენებს. აპლიკაცია, რომელიც სერვისის ანგარიშს იყენებს, გარე სისტემაა და საჯარო API-ს API გასაღებით იძახებს. იდენტობის მომწოდებელი, SMTP და Vault Transit მხოლოდ მაშინ არსებობენ, როცა ეს ინტეგრაცია კონფიგურირებულია.

2. Container / კონტეინერი

svg/02-container.svg

The Angular UI, the Web application, and one database are runtime containers. Redis is a fourth container only when it is enabled. The Angular UI runs in the browser and calls the UI API with the session cookie. The Web application serves the Angular files, the UI API, the Public API, and the Legacy pages that remain. The person and the external systems stay outside the boundary.

Angular UI, Web აპლიკაცია და ერთი ბაზა გაშვების კონტეინერებია. Redis მეოთხე კონტეინერია მხოლოდ მაშინ, როცა ჩართულია. Angular UI ბრაუზერში ეშვება და UI API-ს სესიის ქუქით იძახებს. Web აპლიკაცია Angular-ის ფაილებს, UI API-ს, საჯარო API-ს და დარჩენილ Legacy გვერდებს აწვდის. პიროვნება და გარე სისტემები საზღვრის გარეთ რჩებიან.

3. Web component / Web-ის კომპონენტი

svg/03-web-component.svg

The vault account reaches the Angular files, the Legacy pages, and the UI API. Only an application that uses a service account calls the Public API. SecretService and AuditSink persist through EF Core to the database outside the Web application.

საცავის ანგარიში აღწევს Angular-ის ფაილებს, Legacy გვერდებს და UI API-ს. საჯარო API-ს მხოლოდ ის აპლიკაცია იძახებს, რომელიც სერვისის ანგარიშს იყენებს. SecretService და AuditSink მონაცემებს EF Core-ით წერენ ბაზაში, რომელიც Web აპლიკაციის გარეთ დგას.

4. Focused code: reveal / გახსნის კოდი

svg/04-reveal.svg

`SecretRevealed` is committed before `UnsealAsync`. The earlier `Viewed` row is the details load, and it is written before the access decision.

`SecretRevealed` ფიქსირდება `UnsealAsync`-მდე. უფრო ადრეული `Viewed` დეტალების ჩატვირთვაა და წვდომის გადაწყვეტამდე იწერება.

5. Deployment / განთავსება

svg/05-deployment.svg

Development runs Web on the developer machine and the database in a Compose project on a Docker host. Production runs the Web image on a Docker host behind a TLS reverse proxy, with the database on its own server. The demonstration is one disposable Development run, not another deployment.

Development Web-ს დეველოპერის მანქანაზე უშვებს, ბაზას კი Docker ჰოსტზე Compose პროექტში. Production Web იმიჯს Docker ჰოსტზე უშვებს TLS შებრუნებული პროქსის უკან, ბაზა კი საკუთარ სერვერზეა. დემონსტრაცია Development-ის ერთი ერთჯერადი გაშვებაა, არა სხვა განთავსება.
